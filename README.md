# 🌤 Weather App

Weather application for viewing current weather and forecast in cities around the world with favorites support.

## Features

- 🔍 Search cities in any language
- 📍 Autocomplete with geocoding
- 🌡 Current weather
- 💨 Wind speed
- ☁ Cloudiness
- 💧 Humidity
- 👀 Visibility
- 🌅 Sunrise / Sunset
- 🌍 Coordinates
- 📈 Temperature forecast:
    - next 24 hours
    - weekly forecast
- ❤️ Favorites
- ⚠ Maximum 5 favorite locations
- 💾 Local backend using json-server
- 📱 Responsive design
